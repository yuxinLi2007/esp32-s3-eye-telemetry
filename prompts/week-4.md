# 第 4 周任务：用自然语言查询与请求采集

> 本周在既有（第 1—2 周）查询/采集接口之上接入自然语言入口。运行位置：自建服务端（VPS/本地），
> 开发智能体只做开发辅助，不参与产品运行时。

## 一、本周目标（课程第 4 周）

把"查看上次数据"和"重新采集一次"这两类请求映射成两个不同的任务，并复用第 1—2 周已验证的接口：
- 查询 = 读取已有记录（不改设备行为）；
- 请求采集 = 下发一条带 `request_id` 的远程采集指令（改变设备行为，必须走指令通道）。

## 二、功能要求（验收点）

1. **自然语言查询与请求采集分离**：同一句自然语言必须被明确分类为 `query` 或 `collect`，
   生成的回答互不混淆；"查看上次数据"不得触发采集，"重新采集"不得只回显旧数据。
2. **接入授权语言服务（结构化输出）**：运行时语言模型与开发助手分开配置（环境变量隔离）；
   模型输出必须是可校验的 JSON（意图 + 参数），解析失败/超时/无密钥时降级到确定性规则解析，
   任何情况下都必须给出答复，不允许整个功能失效。
3. **参数校验与设备范围**：采集参数（n / interval_ms）复用服务端 `commands.validate_params`
   的唯一一份范围校验；目标设备 MAC 必须是本系统见过的设备（或环境变量白名单内的设备），
   不允许对陌生设备下发采集。
4. **歧义处理**：一句请求同时命中查询与采集、或存在多台已知设备而用户没说哪台时，
   必须停下来追问（clarify），不猜测、不默认、不随便选一台。
5. **诚实性（本周最重要的验收点）**：无设备完成证据时不得回复"已采集成功"。
   回答只能由真实结果驱动：
   - 指令刚下发 → 只能答"已受理/等待设备执行"（附 request_id）；
   - 设备执行完成且服务端实收样本 → 才能报"采集完成，服务端实收 N 条新样本"；
   - 设备失败/超时/无人领取 → 如实报出对应状态；
   - 查询旧数据时若最后一批已经很旧，必须说明时间与"不能当作当前状态"，
     不得把旧数据说成现状。

## 三、本仓库上下文（必须遵守的既有事实）

- 接口（**不改路径、不改轮询间隔**）：
  - `GET /api/v1/readings?limit=` 查询样本（含 `trust.counts`、`gaps`）；
  - 采集必须走 `POST /api/v1/commands`（op=capture，参数 n/interval_ms，带 client_token）
    并用 `GET /api/v1/commands/{request_id}` 轮询结果；
  - 新增的助手接口可加新路径（如 `/api/v1/assistant/chat`），但不得改动上面这些。
- 前端轮询间隔保持 2s；`node tools/ui_check.mjs` 是硬门槛，它断言：
  - `index.html` 第一个 `<script>` 内必须存在函数 `buildSeries / trustOf / TRUST_TEXT / stopIntervals`；
  - DOM id 不得删除或改名：`alarm cards prov ctl_state btn_start btn_stop cmd_ops cmd_stats cmd_tbody cmd_mac cmd_note`；
  - `commands.js` 必须仍按 `/api/v1/commands/ops` 渲染按钮、连点 3 次 ping 只产生 1 次 POST（防抖必须保留）。

## 四、UI 约束（必须逐条满足）

- 单文件页面（无构建、无 CDN；`commands.js` 因 ui_check 按文件读取而保留拆分，其余逻辑内联进 index.html）。
- 不改 API 路径与轮询间隔。
- 不删除或重命名 ui_check.mjs 断言的 DOM。
- 页面 **只留**：报警条（仅异常时出现）、实时曲线（缺口为红色竖带）、三项指标卡
  （最后接收时间 / 采样率 / NTP 可信等级）、采集开关、指令输入区（本周加入自然语言输入区）。
- 删除所有解释文字、派生字段、调试信息、版本号、Git 链接。
- 底色白或极浅灰；单强调色红；无边框、无阴影、无分隔线；圆角 ≤6px；不用渐变与 emoji；
  窄屏不横向滚动（表格等用容器内滚动）。

## 五、护栏

- 不直接推 main，只在 `week-4-redo` 分支上提交；不自动合并。
- 一次只做这一周，不夹带第 5 周及以后的改动。
- 失败即停：ui_check 不过就停，保留日志，不开 PR。
- .env / 密钥不入库；语言服务密钥只写在服务端环境变量。

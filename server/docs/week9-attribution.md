## 期末迁移决定（提交项：确定个人项目期末迁移的一个交互模块及验证任务）

- **迁移模块**：**"按需环境快照 + 主动重拍询问"交互闭环**（第 7/8/9 周合体）——
  用户按需拍照 → 视觉可用性判定（标签+分数，未校准口径）→ 画面不可用时
  系统主动问"要重拍吗" → 确认走 image 指令重拍 / 忽略走冷却 → 新图再次判定。
  选它因为在三个周次中它验证得最完整、与 ESP32-S3 端侧耦合最小、是"交互闭环"
  的直观展示。
- **验证任务**：遮挡 → 系统询问 → 确认重拍 → 新图判定为可用 → 零追问；
  以及拒绝（忽略）→ 冷却期内再遮挡不打扰。验收断言即本周
  `test_asks.py` 的当堂验证两条 + `demo_week9.py` S1/S2 段落。
- **端侧适配（后续）**：把演示中 claim/传图/done 换成 ESP32-S3 真实固件
  （fw ≥ 0.9.0 支持 image 指令），在板卡上重跑同一验证任务。
